# v1 is accepted when the Instrument reports honestly, not when it shows a win

The obvious acceptance bar for this project is "the Layer beat the Foundation." We are deliberately
not using it. Defining done as a positive result creates direct pressure to tune the Layer until it
wins — which is exactly the overfitting that Holdout Fixtures exist to prevent, and it would quietly
destroy the credibility of every number the Instrument produces afterwards.

v1 is done when the Sweep runs end to end, all four claims (efficiency, product fit, Divergence,
Discovery) produce numbers, and the report site renders. Whatever the result says, it says. A null
result is a legitimate v1 outcome — and in a room, a more convincing one: we built something that
could have told us we were wrong, and here is what it said.
